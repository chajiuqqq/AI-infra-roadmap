# Inference Engineering Hub · 推理引擎能力路线图

面向推理引擎能力建设的中文学习网站，包含六阶段路线、蓝图评估、项目实践与参考阅读。

在线网站：[Inference Engineering Hub](https://inference-engine-roadmap.chajiuqqq.chatgpt.site/)

## 内容

- S0–S5 六阶段学习路线、阶段目标与能力验收。
- 每阶段思维导图，梳理任务、概念、实践与成果。
- 18 个「怎么学」步骤，每一步包含待办、需要回答的问题和输出物。
- 项目阶梯，以及博客、书籍、课程、论文和开源项目等阅读资料。
- 学习进度与笔记、搜索、深色模式和打印支持。

## 本地运行

这是纯静态网站，无需安装前端依赖。在仓库目录运行：

```sh
python -m http.server 8000 --directory dist
```

浏览器打开 <http://localhost:8000>。也可以直接打开 `dist/index.html`；建议使用本地服务预览。

## 源码结构

```text
dist/
  index.html     页面入口、基础样式、路线数据和主要交互
  learning.js    思维导图、学习步骤、问题、待办和补充阅读
  learning.css   学习模块的样式
```

修改源码后刷新页面即可看到更新。`dist` 中的文件就是可直接部署的完整网站，无需构建。

## 部署

将 `dist` 目录发布到任意静态网站托管服务即可。使用 GitHub Pages 时，可通过 GitHub Actions 上传 `dist` 目录作为 Pages 部署产物。当前在线网站由 Sites 托管；向此仓库提交代码不会自动更新该在线网站。

## 学习数据

待办勾选、笔记和显示偏好保存在浏览器本地存储中，不会上传服务器。不同浏览器、设备或网站地址之间不自动同步；清除网站数据会清除这些记录。
